## Requirements

안정적으로 빌드하기 위해서는 프로젝트 타겟 및 패키지 타겟도 ios13 이상으로 설정해주세요.

## Installation

IAPManager is available through [CocoaPods](https://cocoapods.org). To install
it, simply add the following line to your Podfile:

```ruby
pod 'IAPManager'
```
